# Solfège

Application d'initiation au solfège : 25 leçons, 8 jeux de lecture, jeu d'oreille (intervalles, gammes et arpèges, phrases) et outils (métronome, accordeur, piano). Installable, fonctionne hors-ligne.

Ce dépôt ne contient que le site compilé. Partitions et son : moteur de Scorsaire ; SoundFonts hébergées sur GitHub Pages (`scorsaire-lecteur`), moteur léger de secours.

Utilisable seule (ce site) ; destinée à être intégrée plus tard dans un portail.
